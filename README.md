# DriveFix - Smart Vehicle Care Micro Project

DriveFix is a simple, modern, page-wise vehicle repair website.

## Flow

1. Login / Sign Up
2. Vehicle Registration
3. Select Vehicle Problem
4. Repair Solution + Estimated Cost
5. Final Repair Request Summary

## Problems included

- Tyre puncture
- Battery
- Brake problem
- Engine overheating
- Engine issue
- AC not cooling
- Oil leakage
- Electrical / lights

## Run

Open the folder in Visual Studio Code and run `index.html` with Live Server.

The two vehicle photos are loaded from Unsplash, so an internet connection is recommended for the images.

## Academic-project note

This is a front-end demo. Login data and requests use browser localStorage. It is not a production authentication system. Cost ranges are indicative demo values, not workshop quotations.
